# ShopEase

A responsive demo storefront inspired by the publicly visible ShopEase landing page.

## Features
- Responsive home page and category sections
- Product cards with distinct image URLs
- Search, category filtering, and price sorting
- Demo shopping bag with add/remove and subtotal

## Run locally
Open `index.html` in a browser. No build step is required.

## Publish with GitHub Pages
Upload `index.html`, `style.css`, `script.js`, `README.md`, and `.gitignore` to your repository. Then go to **Settings → Pages → Deploy from a branch**, choose `main` and `/(root)`, and save.

## Important
This is a recreated starter project based on the publicly visible site, **not the original Lovable source code**. The cart is a front-end demo only; there is no real checkout, payment processing, inventory, account system, or order backend. Product images are remote Unsplash URLs and require internet access. Connect a secure backend/payment provider before accepting real orders.
